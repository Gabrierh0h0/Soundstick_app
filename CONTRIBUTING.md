# Contribuir

¡Gracias por querer ayudar! Soundstick es software libre (GPL-3.0-or-later).

- **Errores:** abre un [issue](../../issues/new/choose) con el modo, la versión y el teléfono. No pegues tu número ni capturas de chats.
- **Ideas y preguntas:** usa [Discussions](../../discussions).
- **Código:** abre un pull request pequeño y enfocado. Antes de enviarlo corre `npm test` y `npm run build`. Los cambios de interfaz se prueban en un teléfono real; el envío a WhatsApp solo funciona en la app de Android.
- **Seguridad:** lee [SECURITY.md](SECURITY.md) y no publiques vulnerabilidades en issues públicos.

Soundstick no es un producto de WhatsApp ni de Meta. No se aceptan cambios que envíen mensajes a otras personas o que eludan los límites de envío.
